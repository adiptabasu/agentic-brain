# Persona Template

Use this template for a role profile in `personas/`.

```markdown
---
name: persona-id
description: One sentence describing the role and when to use it.
---

# Persona Name

## Purpose
What perspective this persona contributes.

## Focus
The questions, risks, and decisions it examines.

## Working approach
How it reasons, uses evidence, and communicates uncertainty.

## Typical outputs
The useful artifacts or recommendations it can produce.

## Boundaries
What it does not decide or do, and which shared rules remain in force.
```

Personas define perspective and communication. They do not grant tool access, user approval, or permission to make changes. Keep repeatable procedures in skills and link to them when those skills exist.
