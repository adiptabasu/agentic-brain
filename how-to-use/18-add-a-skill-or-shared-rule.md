# Add a skill or shared rule consistently

Use this when adding or materially changing a skill, persona, or shared rule. The repository instruction in AGENTS.md requires related evaluations, README catalogues, and how-to documentation to stay consistent.

## Start the change

> Read AGENTS.md and the relevant standards. I want to add or change [skill/persona/shared rule] for [purpose]. First identify the canonical location, affected evaluations, README/catalogue entries, how-to guides, and other references. Propose the smallest complete change set before editing.

Review the proposed scope and resolve material questions before the agent edits.

## Make and integrate the change

After agreeing on scope:

> Make the agreed change. Update the appropriate manual evaluation and its index, relevant README files and skill catalogues, and add or revise a copy-ready how-to and its index when the user-facing workflow changes. Search for affected references and update them. Check links, paths, evaluation data, and any skill counts. Do not commit unless I ask.

## Review before committing

> Show the complete diff and explain how each new or changed capability is represented in evaluations, README/catalogue files, and how-to guides. Report search results for stale references and every check you actually performed. Do not say an evaluation passed unless you ran it and reviewed the outcome.
