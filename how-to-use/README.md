# How to use Agentic Brain

This guide describes the project's basic operating rules, including trust boundaries and verification. Start with [Ask before assuming or changing state](01-operating-rules.md).

For role-focused help, see [Choose and combine personas](02-personas.md).

To draft detailed software documents with an appropriate persona viewpoint, see [Choose and combine personas](02-personas.md) and the [write-document skill](../skills/write-document/SKILL.md).

To reduce chat response length while preserving important details, see [Use cheapaioutput](04-cheapaioutput.md). Use `write-document` for commit messages and local prose; use the appropriate implementation skill for code or configuration.

To manage multi-day work across chat sessions, see [Work sessions](05-work-sessions.md).

To create persona-informed plans that stay in session scratch until termination, see [Create and finish a plan](06-create-and-finish-a-plan.md).

To define and review eval scenarios before implementation, see the [define-testcases skill](../skills/define-testcases/SKILL.md).

To implement a reviewed plan, report checks concisely, and iterate until its evals and unit tests pass, see the [develop-to-green skill](../skills/develop-to-green/SKILL.md).

To create a reusable project structure from a working reference project, see the [create-scaffolding skill](../skills/create-scaffolding/SKILL.md).

To collect and validate the exact destination folder before scaffolding, see the [project-destination skill](../skills/project-destination/SKILL.md).

To document an existing project for future sessions, see the [read-initialize-project skill](../skills/read-initialize-project/SKILL.md).

To start or resume a local support issue with a persistent case record, see the [start-support-issue skill](../skills/start-support-issue/SKILL.md).

To draft a client response with internal reasoning clearly separated, see the [client-response skill](../skills/client-response/SKILL.md).

To inspect logs generally or around a specific time, see the [analyze-logs skill](../skills/analyze-logs/SKILL.md).

To discuss an RCA and close an issue with evidence-linked plain-text files, see the [agree-rca-close-issue skill](../skills/agree-rca-close-issue/SKILL.md).

To prepare canonical skills for a specific host, including adding support for another documented host, see [Initialize skills for an agent](03-initialize-an-agent.md).
