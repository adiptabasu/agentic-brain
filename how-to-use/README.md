# How to use Agentic Brain

This guide describes the project's basic operating rules, including trust boundaries and verification. Start with [Ask before assuming or changing state](01-operating-rules.md).

For role-focused help, see [Choose and combine personas](02-personas.md).

To draft detailed software documents with an appropriate persona viewpoint, see [Choose and combine personas](02-personas.md) and the [write-document skill](../skills/write-document/SKILL.md).

To reduce chat response length while preserving important details, see [Use cheapaioutput](04-cheapaioutput.md). Use `write-document` for commit messages and local prose; use the appropriate implementation skill for code or configuration.

To manage multi-day work across chat sessions, see [Work sessions](05-work-sessions.md).

To create persona-informed plans that stay in session scratch until termination, see [Create and finish a plan](06-create-and-finish-a-plan.md).

To prepare canonical skills for a specific host, including adding support for another documented host, see [Initialize skills for an agent](03-initialize-an-agent.md).
