## Invoking a skill

Shortcut syntax depends on the agent host. If the skill appears in the host's picker, invoke it there. Otherwise, ask the agent to read the canonical file and follow it; for example: “Read `skills/probe/SKILL.md` and follow it.” The canonical skill definitions in `skills/` are the source of truth.
